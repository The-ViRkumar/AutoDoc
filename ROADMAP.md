# AutoDoc Roadmap

AutoDoc is built phase by phase. The detailed plan, the status of every phase and the exit criteria live in
[`autodoc-project/PHASES.md`](autodoc-project/PHASES.md); the decisions behind them are in
[`autodoc-project/PROJECT_LOG.md`](autodoc-project/PROJECT_LOG.md), and every feature carried over from the
original Python AutoDoc is tracked in [`autodoc-project/FEATURE_INVENTORY.md`](autodoc-project/FEATURE_INVENTORY.md).

| Phase | Goal |
|---|---|
| 0 | Preserve the original app, inventory its features, set up the base |
| 1 | A working baseline build of the recorder and editor |
| 2 | Rebrand to AutoDoc |
| 3 | Guide capture: one step per click, with screenshot, window title and keys |
| 4 | Guide editor tab: review, reorder, edit, annotate |
| 5 | Guide export: Markdown, printable page, interactive wizard, zip |
| 6 | Smart captions, redaction, translation |
| 7 | Library, Docs and Settings tabs |
| 8 | Frame extractor and remaining features |
| 9 | Release pipeline, polish, documentation |

Ideas and bug reports are welcome as [issues](https://github.com/The-ViRkumar/AutoDoc/issues).
